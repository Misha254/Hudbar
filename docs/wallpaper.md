# Окно выбора обоев

`hud-wallpaper-rs` — окно выбора обоев HUDbar. Слой `zwlr_layer_shell` в слое
`Overlay` без якорей, поэтому композитор центрирует его сам, а рабочие области
не меняются. Клавиатура `Exclusive`, потеря фокуса закрывает окно.

Ничего из этого документа применять не нужно автоматически: файл объясняет,
что и куда вписать руками.

## 1. Размытие под окном

Слой называет себя `hudwallpaper`. Правило для `~/.config/niri/rules.kdl` —
такое же, как у меню, только с другим namespace:

```kdl
layer-rule {
    match namespace="^hudwallpaper$"
    background-effect { blur true saturation 0.9 xray false }
}
```

Карточка получает прозрачность `CARD_ALPHA` (0.97) — сквозь неё видно, что
именно размывается. Затемнения вокруг нет: под окном должны быть видны
терминал и обои.

Если правило не сработало, окно останется читаемым, просто без размытия.

## 2. Бинды

Текущий вариант — нампад, рядом с остальными биндами HUDbar:

```kdl
super+z repeat=false hotkey-overlay-title="Обои" { spawn-sh "~/.local/bin/hud-wallpaper"; }
```

`repeat=false` обязателен: удержание клавиши не должно открывать окно пачками.

## 3. Старый wall.sh

`wall.sh` остаётся и ничего не теряет:

- `hud-wallpaper` — окно с миниатюрами, мышью и клавиатурой;
- `wall.sh` — запасной путь и источник превью для него;
- `wall.sh --random` — случайный выбор без окна, им же пользуется пункт меню
  «Случайные обои»;
- превью лежат в `~/.cache/wallpaper-previews/` и обслуживаются обеими
  сторонами: окно читает тот же кэш и тем же рецептом (`vipsthumbnail`, иначе
  `magick`), что пишет скрипт.

Если `hud-wallpaper-rs` не установлен, пункт меню «Стиль → Выбрать обои…»
сам откатывается на `wall.sh` — по той же проверке наличия, что и у остальных
пунктов.

## 4. Прямой вход в папку

Обёртка передаёт аргумент бинарнику, поэтому папку можно открыть сразу:

```sh
hud-wallpaper anime    # сразу «anime»
hud-wallpaper          # корневой вид «all» или текущая папка обоев
hud-wallpaper nosuch   # папки нет — корневой вид «all», без ошибки
```

## 5. Управление

Зоны: папки → сетка → схемы.

| Клавиша | Действие |
| --- | --- |
| `↑↓←→` | выбор по зоне |
| `←` из первой колонки сетки | перейти в папки |
| `→` из папок | перейти в сетку |
| `Tab` / `Shift+Tab` | следующая / предыдущая зона |
| `Enter` | применить обои (в сетке), выбрать папку или схему |
| `PgUp` `PgDn` `Home` `End` | прокрутка и концы списка |
| печатные символы | поиск; кириллица ищется по латинице |
| `Backspace` | стереть символ запроса |
| `Esc` | очистить запрос, иначе закрыть |

Мышь: клик по миниатюре выбирает, второй клик по выбранной применяет; клик по
папке и по схеме выбирает; колесо крутит ряды; наведение подсвечивает, но
выбор не двигает.

Применение закрывает окно сразу: пересчёт matugen занимает секунды, а
уведомление присылает сам `wall.sh`. Ошибка уходит в журнал, а не молчит.

## 6. Повторный вызов

Окно держит pid-файл `$XDG_RUNTIME_DIR/hudbar-wallpaper.pid` — свой, чтобы не
затирать pid-файл меню. Слой не виден в `niri msg windows`, поэтому pid-файл
единственный способ узнать, открыто ли окно:

- файл есть, процесс жив → новый запуск посылает старому `SIGTERM` и выходит;
- файл есть, процесса нет (убит или перезагрузка) → файл перезаписывается;
- файла нет → пишется свой pid.

Файл снимается на любом выходе, включая `SIGTERM`. Сбросить вручную, если
залипло:

```sh
rm -f "$XDG_RUNTIME_DIR/hudbar-wallpaper.pid"
```

## 7. Установка

```sh
cargo build --release --bin hud-wallpaper-rs
install -m 0755 target/release/hud-wallpaper-rs ~/.local/bin/
install -m 0755 scripts/hud-wallpaper ~/.local/bin/
```

Затем один раз:

```sh
niri msg action load-config-file ~/.config/niri/config.kdl
```

## 8. Замеры

`~/wallpapers/anime`, 63 файла, релизная сборка, 12 видимых миниатюр, лента
предзагрузки 20. Семь пар прогонов «холодный / тёплый», чередующихся в одной
сессии, медиана и максимум по семи замерам. Холодный прогон — перед ним снесены
превью этих 63 файлов, поэтому `vipsthumbnail` реально срабатывает.

| Метрика | Холодная медиана | Холодный макс | Тёплая медиана | Тёплый макс |
| --- | --- | --- | --- | --- |
| модель: скан `~/wallpapers` + размеры папки | 4.5 мс | 14.7 мс | 4.3 мс | 4.7 мс |
| создание шрифтовых систем окна (один раз) | 29.5 мс | 109.3 мс | 29.9 мс | 32.0 мс |
| первый кадр с заглушками | 182.2 мс | 282.2 мс | 185.1 мс | 193.5 мс |
| кадр в цикле, шрифты созданы один раз | 163.9 мс | 167.3 мс | 164.4 мс | 167.2 мс |
| загрузка 12 миниатюр | **1598.7 мс** | 1880.8 мс | **10.4 мс** | 10.5 мс |
| кадр с 12 готовыми миниатюрами | 343.9 мс | 369.1 мс | 177.1 мс | 214.4 мс |

Как читать:

- первый кадр не ждёт диск и одинаков в обоих случаях — он рисует заглушки;
  нагрев кэша глифов виден только в нём (182 мс против 164 мс в цикле);
- загрузка отличается на два порядка: 1599 мс против 10.4 мс, то есть
  превью, сгенерированные один раз `wall.sh`, читаются практически бесплатно;
- холодный «кадр с 12» дороже тёплого вдвое (344 против 177 мс) не из-за
  отрисовки, а из-за двух `vipsthumbnail`, которые в этот момент ещё работают и
  занимают оба потока загрузчика;
- максимумы по модели и шрифтам — первый запуск в сессии: 14.7 и 109.3 мс
  против медиан 4.5 и 29.5, то есть холодный файловый кэш страниц.

Первый кадр рисуется сразу, миниатюры догружаются в фоне двумя потоками:
видимые первыми, соседние ряды — следом. При прокрутке устаревшие задания
отбрасываются по счётчику поколения, кэш в памяти — LRU на 128 миниатюр.

## 9. Чек-лист ручной проверки

- [ ] `hud-wallpaper` открывает окно поверх панели, рабочие области не меняются.
- [ ] первый кадр появляется сразу с заглушками, миниатюры догружаются следом.
- [ ] миниатюры соответствуют файлам: имя и ratio под каждой своей.
- [ ] клик по миниатюре выбирает, второй клик применяет и закрывает окно.
- [ ] клик по папке открывает её сразу; колесо листает ряды без прыжков выделения.
- [ ] `←` из первой колонки уводит в папки, `→` из папок возвращает в сетку.
- [ ] `Tab` и `Shift+Tab` гоняют зоны по кругу в обе стороны.
- [ ] печать по-русски и по-английски фильтрует, кириллица находится по латинице.
- [ ] `Esc` при непустом запросе чистит запрос, при пустом закрывает окно.
- [ ] `Enter` в сетке применяет обои со схемой из зоны схем.
- [ ] повторный `hud-wallpaper` закрывает открытое окно, а не открывает второе.
- [ ] `hud-wallpaper anime` открывает сразу папку; `hud-wallpaper nosuch` — корень.
- [ ] клик по крестику в поиске очищает запрос.
- [ ] `pgrep -f hud-wallpaper-rs` после закрытия не находит процесса.
